# #107 [RM-13] Add disabled-by-default ad slots with lifecycle and layout verification

## Architecture clarification — 2026-10-15

KIRARI uses the hosting provider's native deployment mechanism. GitHub Actions validates source and produces optional portable artifacts, but does not duplicate the provider's native release controller.

Consent/provider/CSP/Astro lifecycle remain product requirements independent of release orchestration. Owner privacy/provider decisions remain necessary; default-off behavior remains mandatory. No deployment-controller requirements apply.

---

GOAL
Provide an explicit opt-in display-ad module while preserving static sponsor content and the existing ads.txt contract.

SCOPE
Add named owner-configurable slots and provider adapters starting with AdSense content/auto/manual and static sponsor; keep provider IDs and placements in Site config; integrate with consent/CSP; handle Astro navigation lifecycle and reserve space to avoid preventable shifts. Distinguish ordinary display ads from Google Programmable Search AdSense mode. Preserve publisher-owned root ads.txt support already implemented.

OUT_OF_SCOPE
No default ad requests, no arbitrary remote scripts as ordinary TOML data, no new network without owner choice, and no duplicate ads.txt implementation.

ACCEPTANCE_CRITERIA
- Ads disabled by default makes zero third-party ad-network requests.
- Missing slot configuration renders safely without errors.
- Fresh load and client navigation do not initialize slots repeatedly.
- Consent, CSP and reserved-space behavior are verified; publisher ads.txt reaches public root.
- Existing search-ad mode remains clearly separated and its local/preview suppression policy is decided.

DEPENDENCIES
Owner chooses providers, account/slot model and preview policy; RM-01 Site config contract and RM-12 shared consent policy.

DELIVERY_EVIDENCE
Owner decision record, zero-request disabled capture, enabled fixture browser/network results, navigation and layout-shift evidence.

SOURCE_ROADMAP
KIRARI_NEXT_SPEC.md §7 and §11; external Site POC explicitly deferred Ads/Consent; current ads.txt mapping is already implemented.
