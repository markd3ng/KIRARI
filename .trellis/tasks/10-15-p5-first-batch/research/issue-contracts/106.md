# #106 [RM-12] Audit and gate configured analytics providers with consent

## Architecture clarification — 2026-10-15

KIRARI uses the hosting provider's native deployment mechanism. GitHub Actions validates source and produces optional portable artifacts, but does not duplicate the provider's native release controller.

Consent/provider/CSP/Astro lifecycle remain product requirements independent of release orchestration. Owner privacy/provider decisions remain necessary; default-off behavior remains mandatory. No deployment-controller requirements apply.

GOAL
Keep existing visitor analytics disabled by default and make enabled providers follow an explicit owner privacy/consent policy without duplicate SPA pageviews.

SCOPE
Audit only the existing documented providers (GA4, Umami, Plausible, Clarity, Fathom, Simple Analytics, Matomo and Amplitude); record initialization, navigation, events, consent and CSP needs; define a unified event vocabulary/provider adapters without duplicate automatic pageviews; add owner-configured consent/opt-out and verify fresh load, route/back-forward navigation and disabled state.

OUT_OF_SCOPE
No new provider including Cloudflare Web Analytics without historical/product authorization; no assumption that any provider is enabled in production; no legal policy selected by the implementer.

ACCEPTANCE_CRITERIA
- Owner chooses consent basis, persistence/revocation behavior and provider coverage before implementation.
- Disabled by default emits no third-party analytics requests.
- Enabled-provider matrix accurately records native/manual SPA behavior and required CSP.
- Browser/network checks cover initial page, navigation, back/forward, opt-out and duplicate-beacon prevention.

DEPENDENCIES
Owner consent-policy and provider choices; RM-01 Site configuration contract; RM-09 CSP compatibility for enabled providers.

DELIVERY_EVIDENCE
Decision record, provider matrix, browser/network capture set for each supported provider mode, and verified default-off behavior.

SOURCE_ROADMAP
KIRARI_NEXT_SPEC.md §8 and §11; README analytics settings; external Site POC explicitly deferred Analytics/Consent.
