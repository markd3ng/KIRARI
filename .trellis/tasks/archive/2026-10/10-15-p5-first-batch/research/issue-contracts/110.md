# #110 [RM-15] Package the KIRARI Edge Gateway Cloudflare Workers adapter

## Architecture clarification — 2026-10-15

KIRARI uses the hosting provider's native deployment mechanism. GitHub Actions validates source and produces optional portable artifacts, but does not duplicate the provider's native release controller.

Optional Gateway runtime adapter depends on #102 portable core contract; coordinate export/Preview compatibility with #98 without inheriting P4 approval/admission. Preserve token/cache/platform limitations; no adapter deployment is performed.

---

ROADMAP_ID=RM-15
PROPOSED_PHASE=P5_INDEPENDENT_HARDENING
PRIORITY=P2

GOAL
Package the KIRARI Edge Gateway Cloudflare Workers runtime adapter for the portable core defined by #102.

SCOPE
Implement only the Cloudflare runtime handler, `/_kirari/edge/*` routing, explicit bindings/secrets, and Cloudflare cache adapters required by the #102 capability contract. Map `CACHE_NONE`, `CACHE_EDGE`, and `CACHE_PERSISTENT` to supported primitives; record that Cache API entries are data-center local and Workers KV is eventually consistent. Document Wrangler routing, Service Binding use where applicable, preview configuration, and limits. Keep Gateway credentials server-side and use them only for approved upstream REST calls.

OUT_OF_SCOPE
- Site static artifact packaging, Site-owned Pages Functions, and staging in #98.
- Production/staging deployment, production secrets, or a broad rewrite of Site routing.
- General-purpose proxy paths or platform-equivalent cache claims.

ACCEPTANCE_CRITERIA
- The adapter delegates request semantics to the portable core and exposes only #102-approved routes.
- Methods, path/query allowlists, fixed upstreams, body limits, and health behavior are covered by tests.
- Secrets never reach browser responses/logs; no credential-backed call is enabled without an approved binding.
- Cache behavior is tested/documented with local Cache API scope and KV consistency limitations; unsupported modes degrade explicitly.
- Cloudflare runtime route packaging and preview setup are documented without invoking a deploy.
- Site export/Preview validation remain owned by #98.

DEPENDENCIES
#102 capability/core contract. Coordinate any later same-origin Site package integration with #98 without duplicating Site output packaging.

DELIVERY_EVIDENCE
Adapter contract and route map, focused runtime/cache/security tests, Wrangler/preview package configuration, and no-deploy verification.

PLATFORM_TARGETS
Cloudflare Workers Web runtime, routing, Cache API, KV, secrets, and previews are documented; Cache API scope and KV consistency must remain visible.
