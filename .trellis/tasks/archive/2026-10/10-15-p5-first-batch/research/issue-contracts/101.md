# #101 [RM-07] Deliver LLMs v2 indexes and Markdown views

## Architecture clarification — 2026-10-15

KIRARI uses the hosting provider's native deployment mechanism. GitHub Actions validates source and produces optional portable artifacts, but does not duplicate the provider's native release controller.

LLM discovery is a build-output/application capability without P4 admission dependency. Preserve llmstxt.org-aligned discovery, canonical/base-path and multilingual Markdown views; P6 removes the existing legacy llms-small.txt output and references without adding a shim; this deployment correction does not reintroduce it. Native-hosting HTTP observation is validation evidence, not an approval ceremony.

GOAL
Make KIRARI content discoverable through concise path/language-aware indexes and useful Markdown content views.

SCOPE
Generate curated path/language indexes and Markdown views from content/source AST where available; preserve links, code, math and diagram meaning; add alternate/describedby discovery where supported; validate canonical/base-path, locale, drafts, visibility and relative assets; remove llms-small.txt from output, sitemap, links, config comments and docs without a shim.

OUT_OF_SCOPE
No assumption that llms.txt is a ratified standard; no redirect/alias for llms-small; no decision to retain or remove llms-full.txt within this issue.

ACCEPTANCE_CRITERIA
- Index shape, scope, language and URLs meet the documented output contract.
- Markdown views preserve supported content constructs and exclude drafts/nonpublic content.
- HTML discovery metadata is emitted and resolves to canonical views.
- llms-small.txt and all direct references are absent.
- llms-full.txt policy is recorded as a separate owner decision.

DEPENDENCIES
Completed RM-04 portable export/browser fixtures as reusable validation baseline; owner separately decides public llms-full.txt retention.

DELIVERY_EVIDENCE
Output-contract checks for indexes/views, multilingual/base-path fixtures, browser/header discovery evidence, and generated-file/sitemap/reference scan.
